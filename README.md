# Student Task Manager

A basic web application that allows students to create and manage a list of tasks. Users can add tasks, mark them as completed, and delete them when they are no longer needed.

## Features

* Add a new task
* Mark a task as completed
* Delete a task
* Alert when an empty task is submitted
* Simple and clean user interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
Student-Task-Manager/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How It Works

1. Enter a task in the input field.
2. Click **Add Task**.
3. The task is added to the task list.
4. Click **Complete** to mark the task as completed.
5. Click **Delete** to remove the task.

## How to Run

### Using a Browser

Open `index.html` directly in a web browser.

### Using a Local Server

If Python is installed, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
